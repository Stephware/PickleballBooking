# The Mad Pickle — marketing media

Place approved images in `logos/logo.png`, `hero/hero.jpg` and
`courts/court-1.jpg`, `court-2.jpg`, etc. Image discovery is automatic
for named presets except the established Reserve legacy gallery.

Photos, logos and promotional images must be public-safe and authorized by
the venue. Do not upload client receipts or private documents here.
See [venue library guidance](../README.md) for the exact file convention.
